Age of War 3DS - aow3ds.cia

QR 안에는 CIA 의 직접 다운로드 링크가 들어있다.

https://github.com/spidychoipro/Age-of-War-3DS/releases/download/v0.1.1/aow3ds.cia
  1. 3DS 카메라(FBI)로 QR 을 읽으면 CIA 를 바로 내려받아 설치한다.
  2. 1. FBI 실행
  3. 2. Remote Install → Scan QR code
  4. 3. 이 화면을 보면서 3DS 카메라로 QR 을 읽는다
  5. 4. 아래 화면에서 Yes
  6. SD 카드로 설치하려면 aow3ds.cia 만 내려받아 FBI → SD → Install and delete CIA.
  7. 개발용 title ID(0x0003FF3F)라서 시그패치가 있는 커스텀 펌웨어에서만 설치된다.
